# 그림 넣는 법

지금 캐릭터와 배경은 **전부 임시 도형이다** (`js/chars.js`의 사각형, 각 게임의 `fillRect`).
그림이 준비되면 여기에 파일을 넣고 `js/assets-manifest.js`에 한 줄 적으면 된다.
**게임 코드는 한 줄도 안 고친다.**

하나씩 바꿔도 된다. L모자만 그려서 넣으면 L모자만 그림이 되고 나머지는 도형으로 남는다.

## 폴더

```
assets/
  chars/   캐릭터 스프라이트 시트
  bg/      배경 한 장
  icon/    앱 아이콘 (탭 아이콘 · 폰 홈 화면). python tools/make-icon.py 로 생성
  sample/  견본. 형식을 눈으로 보고 배선이 도는지 확인하는 용도
```

아이콘은 임시로 만들어 둔 것이다 — 빨간 모자에 L 마크.
**캐릭터 스프라이트를 그리면 아이콘도 같이 바꾸는 게 좋다** (`tools/make-icon.py` 또는 직접 교체).

폰에서 **홈 화면에 추가**하면 이 아이콘이 뜨고, 조카에게 폰을 쥐여줄 때마다
주소를 치지 않아도 된다.

## 먼저 견본으로 확인

그림을 그리기 전에, **넣으면 정말 바뀌는지** 먼저 본다.

```sh
python tools/make-sample-assets.py     # assets/sample/ 생성 (이미 들어 있다)
```

`js/assets-manifest.js`에서 `assets/sample/lhat.png` 줄의 주석을 풀고 TV 화면을 열면
L모자만 그림으로 바뀌고 나머지는 도형으로 남는다. 그게 정상이다.

견본 캐릭터 왼쪽 위의 **흰 눈금은 칸 번호**다 (1칸=1개, 2칸=2개…).
시트를 만들 때 어느 칸이 어느 자세인지 세어보라고 넣은 것이고, 진짜 그림에는 넣지 않는다.

## 캐릭터

**가로로 이어붙인 스프라이트 시트.** 자세 하나가 한 칸이다.

```
lhat.png  (96 × 160 짜리 4칸 = 384 × 160)

 ┌──────┬──────┬──────┬──────┐
 │ idle │ jump │squat │punch │
 └──────┴──────┴──────┴──────┘
    0      1      2      3
```

- **발이 프레임 아래 끝에 닿게** 그린다. 기준점이 발밑 중앙이다
- 배경은 투명(PNG)
- 크기는 자유. 화면에서는 키(높이)에 맞춰 늘어난다. **96 × 160 정도면 720p에서 충분하다**
- 자세가 idle 하나만 있어도 된다. 없는 자세는 idle로 그려진다

매니페스트:

```js
lhat: { src: 'assets/chars/lhat.png', fw: 96, fh: 160,
        poses: { idle: 0, jump: 1, squat: 2, punch: 3 } },
```

캐릭터 id 여섯 개: `lhat` `mario` `luigi` `peach` `bowser` `toad`
(주인공은 `lhat` — M 대신 L 마크의 빨간 모자. PROJECT.md 3장)

## 배경

**게임 하나에 한 장.** 1280 × 720으로 그리면 `drawImage` 한 번에 끝난다.

| 파일 | 게임 | 주의 |
|---|---|---|
| `bg/jumprope.png` | 줄넘기 | 바닥선이 **높이의 80%** 지점 |
| `bg/hammer.png` | 해머 피하기 | 바닥선이 **84%** 지점. 세로 3등분이 보이면 좋다 |
| `bg/blockbreak.png` | 블록깨기 | 가운데 위쪽이 격자 자리. 비워둔다 |
| `bg/ropeclimb.png` | 로프 오르기 | **세로로 이어진다.** 아래 참고 |

로프만 세로로 흐른다. **위 끝과 아래 끝이 맞물리게** 그려야 이음매가 안 보인다.
높이는 **720 이상**으로 — 그보다 작으면 화면을 채우느라 `drawImage` 횟수가 는다.

## 지켜야 할 것 (phase1 예산)

조카 집은 스마트TV 내장 브라우저다. 예산은 `js/config.js`에 있다.

- **한 프레임에 `drawImage` 150(가중치 합) 이내.** 배경 1 + 캐릭터 4면 5 정도다. 여유는 많다
- **파일 크기를 키우지 않는다.** 1280×720 PNG 한 장이 500KB를 넘으면 TV가 로딩에서 버벅인다.
  색 수를 줄인 PNG(팔레트) 또는 품질 80 정도의 JPEG를 권한다. 캐릭터는 투명이 필요하니 PNG
- **그림자·블러를 그림에 구워 넣는 건 괜찮다.** 실시간으로 거는 것만 금지다 (`ALLOW_SHADOW: false`)
- 그림을 고치면 **파일 이름에 숫자를 붙인다** (`lhat_2.png`). 배포본 캐시가 일주일이라
  같은 이름으로 덮으면 TV가 옛날 그림을 계속 쓴다 (PROJECT.md 11장)

## 넣고 확인하기

```
GP_STATIC=. python server/main.py
→ http://127.0.0.1:8000/tv/index.html?fps=1
```

- 그림이 안 뜨면 매니페스트의 경로 오타를 먼저 본다
- 브라우저 콘솔에서 `GP.assets.status()` — 몇 개 받았고 무엇이 실패했는지 나온다
- fps 오버레이의 `draw`와 `cost`가 예산 안에 있는지 본다

받는 중에는 임시 도형이 나온다. **로딩 화면은 없다** — 5세는 로딩을 기다리지 않는다.

## 캐릭터 교체 경고

지금 캐릭터는 원작(마리오·루이지·공주·쿠파·키노피오)을 그대로 쓴다.
**집에서만 쓰는 전제다.** 외부에 공개하려면 전부 교체해야 한다 (PROJECT.md 3장).
