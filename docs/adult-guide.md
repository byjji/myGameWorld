# 어른용 한 장 — 조카 집에서 시작하기

> 설명 없이 시작할 수 있어야 한다. 이 문서를 조카 집에서 꺼내 볼 일이 없으면 성공이다.

## 1. TV에서

리모컨으로 주소창에 **한 줄**만 친다.

```
<도메인>
```

방 코드 네 자리가 화면 1/3 크기로 뜬다. 숫자는 **2 3 4 5 8 9**만 나온다.

## 2. 폰에서

```
<도메인>/p
```

1. TV에 뜬 숫자 네 개를 누른다. 확인 버튼은 없다 — 네 번째를 누르면 바로 들어간다
2. 캐릭터를 고르고 **준비 완료**
3. **센서 권한을 묻는다면 허용.** 이게 없으면 동작이 안 잡힌다 (아이폰은 반드시 물어본다)

폰이 두 대 이상이면 각자 같은 코드를 넣는다. **최대 네 명.**

## 3. 놀기

```
놀이 고르기(룰렛) → 동작 시연 → 자세 맞추기 → 3‧2‧1 → 한 판(90초) → 결과 → 보드
```

이 고리가 **다섯 판** 돌면 오늘의 파티가 끝난다.

- **룰렛**: 폰을 위로 흔들면 돌아간다. 12초 동안 아무도 안 흔들면 알아서 돈다
- **어른이 고르고 싶으면**: 폰을 좌우로 기울여 카드를 가리키고 위로 툭 쳐올린다
- **자세 맞추기**: 폰을 가슴에 대고 3초 똑바로 서 있으면 된다. 게임마다 다시 한다
- **보드**: 판 결과만큼 말이 움직인다. 별을 많이 모은 사람이 이긴다
- 끝나면 폰을 흔들어 다시 시작

## 4. 동작 네 가지

| 게임 | 시키는 것 |
|---|---|
| 줄넘기 | 줄이 발밑에 올 때 **뛴다** |
| 로프 오르기 | **앉았다 일어난다** |
| 해머 피하기 | 폰을 **좌우로 기울인다** |
| 블록깨기 | 기울여 고르고 **위로 툭 쳐올린다** |

폰은 **가슴에 대고 잡는다.** 손에 들고 흔들면 판정이 흐려진다.

## 5. 잘 안 될 때

| 증상 | 먼저 볼 것 |
|---|---|
| 폰이 "그런 방이 없어요" | TV의 숫자를 다시 본다. TV를 새로고침하면 코드가 유지된다 |
| TV에 빨간 "연결이 끊겼습니다" | 릴레이 서버(NAS)를 본다. `<도메인>/echo`로 통신만 따로 확인 |
| 동작이 안 잡힌다 | 자세 맞추기를 다시 한다. 폰을 가슴에 붙였는지 본다 |
| 폰 화면이 꺼진다 | 폰 하단에 "화면이 꺼지면 다시 켜주세요"가 떠 있으면 그 폰은 자동 유지가 안 된다 |
| 소리가 안 난다 | TV 브라우저가 소리를 막은 것이다. **폰에서 대신 소리가 난다** — 정상이다 |
| 조카가 폰을 본다 | 폰에는 볼 것이 없다. "TV를 보세요"만 뜬다. TV를 가리켜 준다 |

## 6. 개발자용 주소

조카 앞에서는 쓸 일이 없다. 문제를 찾을 때만.

| 주소 | 용도 |
|---|---|
| `<도메인>/?fps=1` | 프레임 수와 그리기 예산을 화면에 표시 |
| `<도메인>/echo` | 통신만 떼어 확인 (연결·왕복·지연·끊김) |
| `<도메인>/bench` | 렌더링 성능 측정 |
| `<도메인>/?game=hammer` | 룰렛을 건너뛰고 그 게임만 반복 |
| `<도메인>/?rounds=2` | 세션을 두 판으로 줄인다 |

## 7. 현장에서 값 바꾸기

조카에게 안 맞는 숫자가 나왔을 때, 노트북을 열지 않고 **주소만 고쳐서** 바로 시험한다.

```
<도메인>/p?tune=SPIKE_ON:10               폰 (판정 임계값)
<도메인>/?tune=ropeclimb.HEIGHT:18        TV (게임별 값)
```

여러 개는 쉼표로. `?tune=SPIKE_ON:10,SQUAT_DOWN_DEG:16`

적용되면 **폰 위쪽과 TV 오른쪽 아래에 "튜닝 N개 적용"이 뜬다.** 안 뜨면 안 먹은 것이다.
없는 이름을 쓰면 빨갛게 "무시 N개"가 뜬다 — 오타를 조용히 넘기지 않는다.

자주 쓸 값:

| 증상 | 바꿀 값 | 방향 |
|---|---|---|
| 점프가 안 잡힌다 | `SPIKE_ON` (기본 12) | 낮춘다 |
| 안 뛰었는데 잡힌다 | `SPIKE_ON` | 올린다 |
| 판정이 늦다 | `JUMP_LAG_MS` (기본 0) | 올린다 (RTT 절반부터) |
| 스쿼트를 얕게 한다 | `SQUAT_DOWN_DEG` (기본 22) | 낮춘다 |
| 로프가 너무 힘들다 | `ropeclimb.HEIGHT` (기본 25) | 낮춘다 |
| 줄넘기가 빠르다 | `jumprope.PERIOD_START` (기본 1.7) | 올린다 |
| 해머가 빠르다 | `hammer.INTERVAL_START` (기본 1.7) | 올린다 |
| 몸을 조금만 기울인다 | `TILT_LANE_DEG` (기본 11) | 낮춘다 |

**여기서 찾은 값은 집에 와서 `js/tuning.js`에 옮겨 적는다.** 주소는 사라진다.
