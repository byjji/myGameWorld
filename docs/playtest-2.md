## 세션 구성

대기 → 캐릭터 → **놀이 고르기(룰렛)** → 시연 → 캘리브레이션 → 카운트다운 → 플레이 → 결과
→ 다시 놀이 고르기. 이 고리가 끊기지 않고 세 판 도는지 본다.

룰렛은 하체 부하가 높은 게임(줄넘기·로프)을 연달아 뽑지 않는다.
겉으로는 랜덤으로 보여야 한다 — 조카가 "왜 이건 안 나와?"라고 물으면 장치가 들킨 것이다.
