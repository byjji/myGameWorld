### 4. 판정

| 항목 | 값 |
|---|---|
| 점프가 안 잡힌 횟수 | |
| 뛰지 않았는데 잡힌 횟수 | |
| 판정이 늦다고 느꼈는가 | |

늦게 느껴지면 두 가지를 순서대로 시도한다. **노트북 없이 주소로 바로 바꾼다.**

1. `/p?tune=JUMP_LAG_MS:60` 부터 (RTT 절반쯤). 올려가며 본다
2. 그래도 늦으면 `js/tuning.js`의 `JUMP_ON_FREEFALL_START`를 `true`로 —
   착지를 기다리지 않고 도약에 발화한다. 이건 숫자가 아니라 재배포가 필요하다

임계값이 안 맞으면 `/p?tune=SPIKE_ON:10` 처럼 그 자리에서 바꿔가며 찾는다.
**찾은 값을 아래에 적어두고**, 집에 와서 `js/tuning.js`에 옮긴다.

| 값 | 기본 | 조카에게 맞은 값 |
|---|---|---|
| `SPIKE_ON` | 12 | |
| `JUMP_LAG_MS` | 0 | |
| `SQUAT_VEL_DOWN` | 0.25 | |
| `SQUAT_VEL_UP` | 0.25 | |
| `TILT_LANE_DEG` | 11 | |

어른 기준으로 맞춘 임계값은 조카에게 안 잡힌다. **조카 기준으로 다시 맞춘다.**
