# Phase 7 — 블록깨기

> 참조: PROJECT.md §5-4, §9-6

## 목표

네 번째 미니게임. **로직 20%, 연출 80%.**
앞선 세 게임과 달리 체력 부하가 낮은 "앉아서 하는" 게임 — 세션 중간의 쉬어가는 자리를 담당한다.

대충 만들면 존재 이유가 사라진다. 단, **TV 성능 한계 내에서** (`js/config.js`의 phase1 예산 상수가 상한).

## 산출물

- `js/games/blockbreak.js`
- 블록 5종 스프라이트 + 파괴 연출 스프라이트 시퀀스
  — **임시로 색 사각형이다.** 종류는 색으로만 구분된다. 실제 스프라이트가 나오면 그리는 자리만 바꾼다
- 코인 획득 애니메이션 (미리 그린 시퀀스) — `gfx.sheet('bb-coin')` 4프레임

## 작업 항목

### 조작

- [x] 3×3 격자
      *`TUNE.GRID`. 조카가 어려워하면 2로 낮춘다 — 고칠 곳이 이 상수 하나다*
- [x] 폰을 좌우로 기울여 **조준** — `motion.js`의 기울기 연속값(`tilt`) 사용, 9칸 매핑
- [x] 위로 툭 **쳐올려서** 블록 파괴 — `motion.js`의 쳐올리기 판정 사용
- [ ] **점프와 쳐올리기 구분이 여기서 처음으로 실전 의미를 갖는다.** 앉아서 하는 게임이라 자유낙하 구간이 안 생기는지 실기 확인
      *게임 쪽은 `punch`만 받고 `jump`는 버린다(시험으로 확인). 실제로 앉은 자세에서
      자유낙하가 안 생기는지는 진짜 센서로만 알 수 있다*
- [x] 조준 커서 이동에 히스테리시스 — 격자 경계에서 떨지 않게
      *칸 경계 양쪽으로 0.35칸의 여유. 그 안에서는 커서가 안 움직인다*
- [x] 격자가 3×3이므로 기울기 해상도는 넉넉. 임계는 여전히 낮게
      *±30도를 9등분해 한 칸당 약 6.7도*

### 블록 종류

- [x] 코인 — 기본
- [x] 버섯 — 5초간 2배
- [x] 스타 — 3초간 조준 없이 전부 파괴
- [x] 빈 블록 — 꽝, 소리만
- [x] 밥밥탄 — **시간 1초 차감** (점수 감점 아님)
- [x] **감점 최소화.** 5세는 마이너스가 뜨는 순간 흥미를 잃는다
      *점수가 내려가는 경로가 코드에 아예 없다. 시험에서도 확인한다*

### 연출 (TV 예산 내)

- [x] 코인 튀어나오는 연출 — **개수 제한 + 미리 그린 애니메이션 스프라이트.** 대량 파티클 금지
      *`gfx.Particles` 풀. 200번 연속으로 깨도 살아 있는 조각은 `MAX_PARTICLES`(24)를 안 넘는다*
- [x] 블록 파괴 시 화면 흔들림은 짧게 (블러·그림자 금지)
      *0.18초, 9px*
- [x] 스타 발동 시 전체 화면 연출 — 프레임 드랍이 나면 스프라이트 수를 줄인다
      *배경색이 바뀌고 격자가 통째로 털린다. 개발 PC에서 `draw 0 · cost 0/150`.
      격자와 배경이 전부 fillRect라 스타 중에도 drawImage는 코인 조각뿐이다*
- [x] 효과음 — 코인·버섯·스타·꽝·밥밥탄 각각 구분
- [x] 폰 진동 패턴을 블록 종류별로 다르게
      *`js/play.js`의 `VIB`. 잘한 것은 짧고 산뜻하게, 밥밥탄은 길고 둔하게*

## 완료 기준

- [ ] 조준 → 쳐올리기 흐름을 조카가 설명 없이 이해한다 (동작 시연 화면만 보고)
      *시연 화면은 만들었다. 커서가 칸을 옮겨 다니고 캐릭터가 쳐올린다*
- [ ] 쳐올리기가 점프로 오인식되지 않는다 (실기 20회 중 오인식 2회 이하)
      *`test/motion-test.js`에서 합성 파형 기준 각 20회 오인식 0. 진짜 팔로는 실기에서*
- [ ] 스타 연출 중에도 30fps 유지 — 미달 시 스프라이트 상한을 낮춘다
      *개발 PC 크롬에서 60fps, `draw 0 · cost 0/150 · text 2/12`. TV 기준은 실기에서*
- [ ] 밥밥탄을 맞아도 조카가 흥미를 잃지 않는다
- [x] 한 판 90초 이내
      *90초 상한. 밥밥탄을 맞으면 그만큼 더 짧아진다 — 시험에서 확인*

## 검증 방법

- 스타 발동 순간을 fps 오버레이(`?fps=1`)로 확인. 실기 확인은 다음 방문 때
- 조카가 조준을 이해 못 하면 조준 방식보다 **연출(커서 크기·색)**을 먼저 손본다
- 앉은 자세·선 자세 양쪽에서 쳐올리기 판정 확인

## 리스크

- 연출 욕심이 phase1 예산을 넘기기 쉽다 → 스프라이트 개수 상한을 상수로 박고 넘으면 드랍
- 3×3 조준이 5세에게 어려울 경우 대비: 폴백으로 격자를 2×2로 줄이는 옵션을 상수로 두고 실기에서 결정
